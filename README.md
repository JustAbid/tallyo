# Tallyo

AI-powered invoice collection assistant: reads customer replies, tracks payment promises, and verifies payments through PayPal Sandbox. Built for the PayPal AI Hackathon 2026.

## Run locally

```
cd server && npm install && npm run dev     # http://localhost:3001
cd client && npm install && npm run dev     # http://localhost:5173
```

Copy `.env.example` to `server/.env` and add your own keys. Never commit `.env`.

## Stack
React + TypeScript + Vite, AG Grid, Node.js + Express, SQLite, PayPal Sandbox.
